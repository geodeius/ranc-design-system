## Analyst interpretation

The stated platform scope suggests that web should be the initial implementation
focus. The internal-administration context may introduce dense data, form, and
workflow needs, but those needs have not been evidenced and must not yet drive
component selection.

The theme model implies shared foundations with controlled product-level
overrides. It must not be implemented as product-specific forks.
