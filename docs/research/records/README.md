# Research Records

Status: Planned

This directory contains completed or in-progress Stage 1 evidence records.

Do not add a record without:

- a named evidence source
- an observation date
- a clear separation between facts and interpretation
- a statement of limitations
- confirmation that the record contains no sensitive customer or production
  data

Copy records from `../templates/`. A template is not evidence and must not be
cited as a research finding.
