# Accessibility Baseline — Unify

Status: In progress

## Record metadata

- Product identifier: Unify
- Surface or journey: Whole product
- Platform: Responsive web
- Evidence reference: Stakeholder responses provided during Stage 1 research
- Observation date: 2026-07-30
- Test evidence: No interface testing performed

## Target

WCAG 2.2 Level AA is the approved accessibility target for the redesign and
design-system work.

## Current reported baseline

The stakeholder reported that Unify does not currently support keyboard-only
navigation and screen readers.

This statement is a portfolio-planning risk, not a verified list of defects or
a conformance assessment.

## Test coverage

- Automated checks: Not run
- Keyboard review: Not run
- Screen-reader review: Not run
- Zoom and text scaling: Not run
- Contrast review: Not run
- Reduced-motion review: Not run
- Touch-target review: Not run
- Error identification review: Not run

## Baseline risks

- Keyboard access and focus management may require redesign rather than
  incremental remediation.
- Screen-reader semantics and announcements may be absent or inconsistent.
- Light and dark themes will each require contrast and focus-state validation.
- Responsive desktop and mobile behavior will require zoom, reflow, target-size,
  and orientation checks.

## Known limitations

- No Unify interface or test environment was supplied.
- No assistive-technology testing has been performed.
- The current level of partial keyboard or screen-reader support is unknown.
- Conformance cannot be claimed until representative journeys are tested.
