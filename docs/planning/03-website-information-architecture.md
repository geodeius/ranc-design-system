## Global Layout

The documentation website should include:

- Persistent top navigation
- Collapsible left sidebar
- Main content area
- Right-side table of contents
- Global search
- Command palette
- Breadcrumbs
- Previous and next page navigation
- Page feedback controls
- GitHub edit link
- Version indicator
- Theme selector
- Responsive mobile navigation

## Homepage

### Hero

```text
Build Rancard products with one shared system.

Reusable foundations, components, patterns, and engineering guidance for creating consistent Rancard experiences.
```

Primary actions:

- Get started
- Browse components
- View engineering guide

### Audience Paths

Create entry points for:

- Designers
- Engineers
- Product managers
- Content designers

### System Categories

Show cards for:

- Foundations
- Components
- Patterns
- Templates
- Engineering

### Platform Status

Display:

- Current version
- Stable components
- Beta components
- Planned components
- Latest release

During Phase Zero, values may be zero or marked as planned.

### Contribution Section

Explain how teams can:

- Request components
- Report problems
- Propose improvements
- Join reviews

## Website Visual Direction

Use:

- Neutral surfaces
- Strong typography hierarchy
- Generous spacing
- Thin borders
- Minimal shadows
- Clear status badges
- High-quality code blocks
- Limited decorative color
- Responsive navigation
- Strong content-density control

The result should feel like a modern engineering platform, not a marketing website.
