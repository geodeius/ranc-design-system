# Documentation application

**Status: Experimental**

This private workspace contains the Phase 2 Next.js and MDX documentation engine and the Phase 3 accessible website shell.

It validates repository-level MDX content, derives routes and navigation from metadata, and renders tables of contents, breadcrumbs, and previous/next links. Phase 3 adds the responsive header, sidebar, mobile navigation, metadata command palette, status badges, theme control, footer, and focus/reduced-motion baselines.

Full-text search indexing and the production visual language remain intentionally
unimplemented for later Phase Zero work.
